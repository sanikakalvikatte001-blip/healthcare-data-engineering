# Healthcare Data Engineering
 
Solutions to common, real-world data engineering problems with healthcare data — one problem a day.

Each project is small, runs on its own, and uses **synthetic data only** (no PHI). Topics come from day-to-day work in healthcare tech: EHR/EMR feeds, HL7 and FHIR, CCDA, claims (837/835), eligibility, HEDIS and quality measures, MPI and patient matching, data quality, and warehouse modeling.

## How each project is organized

```
problems/YYYY-MM-DD-short-name/
├── README.md        # The problem, why it matters, the approach, how to run, results
├── data/            # Small synthetic sample data (generated by the code)
├── src/             # Python / SQL solution
└── tests/           # Tests that prove it works
```

Every project README covers:

- **Problem** — what goes wrong in real healthcare data
- **Why it matters** — impact on reporting, billing, quality, or patient care
- **Approach** — design and key decisions
- **How to run** — commands to reproduce
- **Results** — what the output shows
